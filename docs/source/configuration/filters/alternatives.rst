Alternatives
~~~~~~~~~~~~

   This filter automatically fills alternative fields for symbols. |br|
   You can have various alternative manufacturers, part numbers, etc. |br|
   The names of the alternative fields are created using the `pattern` option. |br|
   To avoid warnings at least one component in the schematic should define the alternative fields,
   you can leave their value empty. In this way KiBot will know these names are valid even before
   running the filter.. |br|
