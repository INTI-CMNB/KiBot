KiCad_SiteAssembly parameters
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~


.. _KiCad_SiteAssembly_name:

-  **name** :index:`: <pair: output - kicad_site - options - assembly_models; name>` [:ref:`string <string>`] (default: ``''``) Name for the downloadable item.

.. _KiCad_SiteAssembly_index:

-  ``index`` :index:`: <pair: output - kicad_site - options - assembly_models; index>` [:ref:`number <number>`] (default: ``0``) Used when the output generates more than one file.
   Here you can select which one, 0 is the first. |br|
   Note that negative indexes are counted from the end of the list. |br|
   Using an out of range value will generate an error and show all available files.

.. _KiCad_SiteAssembly_output:

-  ``output`` :index:`: <pair: output - kicad_site - options - assembly_models; output>` [:ref:`string <string>`] (default: ``''``) Output that generates it.
